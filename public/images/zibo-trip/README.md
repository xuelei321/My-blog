## 需要添加的图片文件

   - 建议：淄博全景或代表性景点

2. **badaju-market.jpg** - 八大局市场
   - 建议：市场内热闹场景或美食特写

3. **bbq-table.jpg** - 烧烤桌全景

   - 建议：炭火烤制中的肉串

5. **bbq-video-cover.jpg** - 烧烤视频封面
   - 建议：吸引人的烧烤场景

   - 建议：中国陶瓷琉璃馆建筑外观

7. **liuli-art.jpg** - 琉璃艺术品
   - 建议：精美的琉璃工艺品特写

   - 建议：博物馆外观或内部展厅

   - 建议：青铜器展品特写

    - 建议：古商城街道或建筑

    - 建议：烧饼特写或制作过程

### 可选图片

- 美食特写（炒锅饼、紫米饼、牛奶棒等）
- 个人旅行照片
- 街头随拍
- 夜景照片

## 图片优化建议

1. **格式**: 使用 WebP 格式，兼容性更好
2. **压缩**: 单张图片建议 < 500KB
3. **命名**: 使用小写字母和连字符，如 `bbq-table.jpg`
4. **备份**: 保留原始高清图片，上传压缩后的版本

## 添加方法

将你的照片复制到 `public/images/zibo-trip/` 目录下，确保文件名与博客中引用的一致。
