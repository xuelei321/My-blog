## 视频优化建议

1. **格式**: MP4 (H.264编码，兼容性最好)
2. **分辨率**: 1080p 或 720p
3. **文件大小**: 单个视频建议 < 20MB
   - 可使用 HandBrake 或 FFmpeg 压缩
4. **帧率**: 30fps
5. **码率**: 2-5 Mbps

## 视频压缩命令（FFmpeg）

```bash
# 压缩为 1080p，2Mbps 码率
ffmpeg -i input.mp4 -vcodec h264 -acodec aac -b:v 2000k -bufsize 2000k -maxrate 2500k -s 1920x1080 output.mp4

# 压缩为 720p，1.5Mbps 码率
ffmpeg -i input.mp4 -vcodec h264 -acodec aac -b:v 1500k -bufsize 1500k -maxrate 2000k -s 1280x720 output.mp4
```
